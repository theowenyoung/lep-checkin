# LEP 打卡助手

LEP 运动小组、读书小组（日卡 / 周卡）的打卡格式生成器：粘贴上一位的打卡，填上自己的内容，一键复制格式正确的打卡。

在线使用：<https://lep.owenyoung.com>

## 用法

1. 打开网页，第一次填好自己的运动组代号、读书组代号和署名。信息会写进网址，收藏这个网址（或拖到桌面）以后打开就自动带上。
2. 选「运动打卡 / 读书日卡 / 读书周卡」其中一个。
3. 在群里复制上一位的打卡，粘贴进来，填上自己的内容，点「复制打卡内容」，去群里粘贴。

工具只改你自己的部分，其余原样照抄上一位。每天 / 每周第一个打卡时，粘贴上一天 / 上一周的最后一条即可，会自动换日期、清零、去掉过期请假。规则依据运动组规 V1.1、读书组规 V1.4，时间按北京时间计算。

整个工具就是一个文件 [`public/index.html`](public/index.html)，不联网也能直接用浏览器打开。所有信息只存在自己的浏览器和网址里，不会上传。

## 部署

部署在 Cloudflare Workers（静态资源），配置见 [`wrangler.jsonc`](wrangler.jsonc)。需要环境变量 `CLOUDFLARE_API_TOKEN` 和 `CLOUDFLARE_ACCOUNT_ID`：

```bash
wrangler deploy
```
